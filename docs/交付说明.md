# 交付说明

## 架构（三层）

```
scenes/**/*.gd + *.tscn     纯视图：布局 / 赋值 / 信号转发 / 切场景
        ↕  UiBridge（唯一门面）
src/bridge/                 极薄桥：查表分派 + Variant 转换 + 信号
        ↕  纯 C#
src/logic/                  逻辑层：Pane 装配 / Port 存档与开局 / Stub 替身
        ↕  直接调用
src/original + src/compat   原版规则内核 + Unity 桩
```

## 关键文件

| 文件 | 作用 |
|---|---|
| `src/bridge/UiBridge.cs` | autoload `UiBridge`：`request(面板)` / `act(面板,动作,参数)` + `panel_snapshot` / `scene_requested` / `toast` 信号 |
| `src/bridge/UiVariant.cs` | C# 数据 ↔ Godot Variant 的纯转换 |
| `src/logic/GameHost.cs` | 立起原版 `GlobalScript` / `GameState` / `TimeScript`，开局，速度 |
| `src/logic/PanelApi.cs` | `IPanel` 契约 + 反射自动注册 |
| `src/logic/Stub.cs` | 替身工厂：造对象图 → 反射调原版 → 读回结果 |
| `src/logic/Port/*` | `GameStateFactory`（预设对象图）、`TimeHostFactory`（时钟宿主）、`SaveService`（反射存档）、`ScienceData`（科技表） |
| `src/logic/panes/*.cs` | 18 个面板：快照装配 + 动作转发 |

## 运行

```powershell
dotnet build
& $env:GODOT_BIN --path .
```

启动日志里 `[UnityRuntime] 运行时泵已启动` 之后若出现异常，说明 `GameHost.Boot()` 的装配缺件（`TimeHostFactory` 与 `GameStartScript` 最可疑）。

## 已知缺口

1. **编译从未验证**：开发环境 bash 被沙箱拒绝，`dotnet build` 没跑过。最可能出问题的三处：
   - `TimeHostFactory`：原版 `TimeScript.Awake` 需要的替身字段是否齐
   - `SaveService`：`Type.GetType(AssemblyQualifiedName)` 在裁剪/AOT 下的解析
   - 替身装配：`DiploButtonScript` / `Doctrine_button_script` 依赖的场景对象树
2. **国家面板特殊按钮**：目前只有 4 个通用互动项（贸易/经合/军事同盟/支持毛派）；原版按国别挑选的宣战、援助、傀儡化等特殊项需要 `CountryScript` 的选按钮逻辑
3. **设置页「事件结束后自动暂停」**：原开关由代码动态生成，按"禁止 GD 造 UI"已删除生成逻辑，需在 `设置.tscn` 补一个 `EventPauseToggle` 节点才能恢复
4. **存档格式**：`SaveService` 是新格式（`user://save_N.dat`），不读原版 `BinaryFormatter` 旧档
